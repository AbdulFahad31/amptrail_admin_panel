# AmpTrail Admin Panel

A modern Flutter Web Admin Dashboard for managing EV charging infrastructure in real-time.

## Overview

AmpTrail Admin Panel is a web-based management platform built using Flutter and Firebase. It enables administrators to monitor charging stations, manage bookings, track slot availability, and oversee user activity through a centralized dashboard.

## Features

### Dashboard
- Real-time monitoring
- Station statistics
- Booking analytics
- User activity tracking

### Station Management
- Add charging stations
- Update station information
- Remove stations
- Monitor station availability

### Slot Management
- View charging slots
- Update slot availability
- Track occupancy status

### User Management
- Monitor registered users
- View booking history
- Manage access

### Authentication
- Firebase Authentication
- Secure admin login
- Session management

## Tech Stack

### Frontend
- Flutter Web
- Dart

### Backend
- Firebase Authentication
- Cloud Firestore

### Hosting
- Vercel
- Firebase Hosting
